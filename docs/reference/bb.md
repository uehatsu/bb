## bb

Bitbucket Cloud CLI

### Synopsis

Work seamlessly with Bitbucket Cloud from the command line.

### Examples

```
  $ bb auth login
  $ bb repo clone myworkspace/myrepo
  $ bb pr create --title "Fix bug" --body "Details"
  $ bb pipeline watch 42
```

### Options

```
      --help      Show help for command
      --version   Show bb version
```
