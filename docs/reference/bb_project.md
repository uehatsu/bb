## bb project

Manage projects in a workspace

### Synopsis

Bitbucket groups repositories into projects. Every repository belongs to exactly one project.

```
bb project <command> [flags]
```

### Options

```
  -w, --workspace string   Workspace (default: configured workspace or current repository's)
```
