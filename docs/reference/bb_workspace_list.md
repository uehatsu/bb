## bb workspace list

List workspaces you belong to

```
bb workspace list [flags]
```

### Options

```
  -q, --jq string         Filter JSON output using a jq expression
      --json strings      Output JSON with the specified fields (comma-separated)
  -L, --limit int         Maximum number of workspaces to list (default 50)
  -t, --template string   Format JSON output using a Go template
```
