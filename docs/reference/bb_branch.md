## bb branch

Manage branches on Bitbucket

### Examples

```
  $ bb branch list
  $ bb branch create feat/x --from main
  $ bb branch delete feat/x
```

### Options

```
  -R, --repo string   Select another repository using the WORKSPACE/REPO format
```
